# AutoEvaluation

CPPu 课程测评辅助脚本。导入 Tampermonkey 或脚本猫后，在测评页面打开问卷即可按配置自动选择选项。

## v2.3

- 修复选项子串污染：`适应` 不再被 `不太适应` / `非常不适应` 一起命中。选项匹配改为「完全相等 → 唯一包含 → 最短包含」三级降级。
- 题干匹配改为最长命中优先，`RULES` 的排列顺序不再影响结果。
- 归一化补上顿号、冒号、破折号，避免规则与页面标点口径不一致导致的静默漏配。
- 勾选后补一次 `input.click()` 兜底；跳过原因带上候选选项文本，便于排查。
- 未配置或匹配异常的题目仍不会提交选择，并用边框标出（橙色：未配置；红色：匹配异常）。

## v2.2

- 通过题干和选项文本匹配，不再依赖选项固定顺序。
- 未配置或匹配异常的题目不会提交选择，并用边框标出（橙色：未配置；红色：匹配异常）。
- 支持实训类问卷的资源、安全检查、教师在岗、训练分组与训练规范题目。
- 全部单选题唯一匹配成功后自动提交；若有未匹配或异常题目，则不会提交。
- 题目规则在脚本的 `RULES` 中配置；请按实际体验调整。
